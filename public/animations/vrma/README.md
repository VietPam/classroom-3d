# Thư Mục Lưu Trữ Hoạt Ảnh VRMA (.vrma)

Thư mục này lưu trữ 5 file hoạt ảnh chuẩn **VRMA (VRM Animation)** dùng chung cho toàn bộ học sinh trong lớp học.

### Danh sách 5 file hoạt ảnh cần thiết:
1. `idle.vrma`: Tư thế đứng nghiêm túc đọc đề bài.
2. `walking.vrma`: Hoạt ảnh chạy đua về ô đáp án.
3. `thinking.vrma`: Tư thế đứng đắn đo, tay chống cằm suy nghĩ tại ô.
4. `celebrating.vrma`: Tư thế nhảy cẫng ăn mừng chiến thắng khi trả lời đúng.
5. `sad.vrma`: Tư thế thất vọng, cúi gục đầu khi chọn đáp án sai.

### Cách tạo file .vrma từ Adobe Mixamo:
1. Tải hoạt ảnh từ Mixamo dạng `.fbx` (Without Skin).
2. Dùng Blender (với Addon VRM for Blender) hoặc công cụ chuyển đổi `mixamo-to-vrma` để retarget sang khung xương VRM.
3. Xuất file với đuôi `.vrma` và thả vào thư mục này.
