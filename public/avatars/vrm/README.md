# Thư Mục Lưu Trữ Mô Hình VRM 1.0 (VRoid Studio)

Thư mục này dùng để lưu trữ các file mô hình học sinh `.vrm` được xuất từ phần mềm **VRoid Studio**.

### Quy chuẩn đặt tên file:
- Học sinh 1 (Bình An): `s1_binhan.vrm`
- Học sinh 2 (Cẩm Tú): `s2_camtu.vrm`
- Học sinh 3 (Đăng Khoa): `s3_dangkhoa.vrm`
- Học sinh 4 (Khánh Linh): `s4_khanhlinh.vrm`

### Lưu ý quan trọng khi xuất file từ VRoid Studio:
1. **Định dạng**: Chọn **Export as VRM 1.0**.
2. **Tối ưu Mobile**:
   - Giảm độ phân giải Texture: $512 \times 512$ hoặc tối đa $1024 \times 1024$.
   - Kéo giảm đa giác (Reduce Polygons): Dưới $12.000$ tris / model.
   - Bật gộp Texture (Delete transparent meshes / Combine materials).
